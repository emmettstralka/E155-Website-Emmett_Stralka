E155 FINAL PROJECT

Invisible Drumset

Air gestures become drum hits. Each stick is an independent embedded system — BNO085, ESP32, FPGA, STM32 — electrically isolated, low latency, eight voices through a DAC.

IMU · I²C / SHTPSPI packetsSystemVerilogSTM32 DAC

Architecture

The original Invisible Drum Set ran on an Arduino Nano and BNO055. This rebuild moves the pipeline onto E155 hardware: STM32 and UPduino FPGA, with an ESP32 handling sensor fusion through the Adafruit BNO08x library after a pure-FPGA SHTP implementation proved unreliable.

IMU data travels I²C to the ESP32, SPI to the FPGA for packaging, then SPI again to the MCU. Gesture logic uses yaw zones, pitch thresholds, and gyro spikes to fire sounds 0–7: snare, hi-hat, kick, toms, crash, ride.

Packet

  • Byte 0 — header 0xAA
  • Bytes 1–6 — roll, pitch, yaw (int16, ×100)
  • Bytes 7–12 — gyro X/Y/Z (int16, ×2000)
  • Byte 13 — validity flags
  • Bytes 14–15 — reserved
